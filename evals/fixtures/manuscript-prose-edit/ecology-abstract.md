# Resource carryover and coexistence in seasonal environments

## Abstract

Species can encounter different competitors when resources persist between seasons. We develop a
model in which resource carryover changes the timing of competition and permits coexistence under
conditions that otherwise favour exclusion. The result concerns the model's assumptions; it does not
establish how frequently this mechanism operates in natural communities.

## Methods

We analysed a deterministic two-species resource model and used simulations to illustrate its
equilibria. Species differ in uptake timing. The model omits immigration, spatial structure and
environmental noise. Simulations supplement the equilibrium argument rather than estimate an
ecological effect in a sampled population.

## Results

The simulation grid contained 1,200 parameter combinations. Both species persisted in 318 combinations
with resource carryover, compared with 72 without it. Each simulation ran for 5,000 seasonal cycles.
These counts describe the chosen parameter grid, not the frequency of coexistence in nature.

## Discussion

Carryover changes which seasonal uptake patterns permit coexistence in this model. This result
highlights the important significance of resource persistence for the model. Whether the mechanism
explains coexistence in a particular community depends on that community's resource dynamics and on
processes the model omits.
